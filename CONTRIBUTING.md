# Contributing

Thanks for your interest in contributing!

## Development Setup

1. Fork and clone the repo
2. Follow the setup instructions in [README.md](README.md)
3. Create a branch for your changes

## Guidelines

- Follow existing code style and naming conventions
- Run `dart analyze` before submitting — aim for zero warnings
- Test on both dark and light mode
- If adding a new screen, follow the existing pattern (screen + widgets + provider)
- Keep commits focused — one feature or fix per commit

## Reporting Issues

- Use GitHub Issues
- Include: steps to reproduce, expected vs actual behavior, device/OS info
- Screenshots are helpful for UI issues

## Pull Requests

- Reference any related issues
- Describe what changed and why
- Keep PRs focused and reviewable (< 400 lines when possible)
